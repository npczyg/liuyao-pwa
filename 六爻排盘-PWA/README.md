# 六爻排盘 PWA

一个只负责排盘、不作吉凶判断的离线网页应用。使用者以三枚乾隆通宝实际起卦，再按初爻至上爻逐次录入正反面，应用自动生成可复制、可保存为图片的完整六爻盘面。

## 已实现

- 三枚乾隆通宝逐枚点击：字面为阴（2），背面为阳（3）
- 六次录入，自动换算老阴、少阳、少阴、老阳
- 北京时间起卦，支持 23 点或 0 点换日
- 年月日时干支、月建、日辰、旬空、前后节气
- 本卦、变卦、八宫归属、宫位阶段、世应
- 京房纳甲、六亲、六神、伏神、本卦卦身与变卦卦身
- 月破、日冲、月合、日合、空亡及常见动爻客观标记
- 六冲、六合、游魂、归魂、伏吟、反吟等结构标记
- 一键复制完整文字，方便直接发送给 AI
- 保存完整盘面图片；iPhone 上优先打开系统分享面板
- 可添加到 iPhone 主屏幕，首次联网打开后可离线使用
- 不保存卦例，不使用账号、数据库或服务器

## 发布与安装

本项目是纯静态网站，不需要构建。将本目录中的全部文件原样上传到任意支持 HTTPS 的静态网站空间，并保证 `index.html` 位于网站入口目录即可。

iPhone 安装步骤：

1. 用 Safari 打开发布后的 HTTPS 网址。
2. 点 Safari 底部的“分享”。
3. 选择“添加到主屏幕”。
4. 此后从桌面上的“六爻排盘”图标进入。

PWA 不能直接通过微信文件或本地 ZIP 安装；必须先有一个 HTTPS 网址。静态网站空间通常可以免费使用。

## 本地测试

需要 Node.js 18 或更高版本：

```text
npm install
npm test
npm run serve
```

然后在浏览器打开 `http://127.0.0.1:4173`。本地地址只用于检查网页；iPhone 添加主屏幕时请使用发布后的 HTTPS 网址。

## 口径说明

- 排盘采用京房八宫纳甲体系。
- 变卦六亲沿用本卦所属宫五行排定。
- 本应用只列客观盘面，不提供吉凶结论。
- 历法计算由已随项目打包的 `lunar-javascript` 完成，运行时不会访问第三方接口。
